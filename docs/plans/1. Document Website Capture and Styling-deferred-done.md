# Document Website Capture and Styling: deferred

Work an agent can do but that could not be finished inside this plan. Each entry: the issue, why it cannot be fixed now, and the trigger or later plan that picks it up. Rename to `-deferred-done.md` once every entry is resolved.

## 1. Plugin listing icon

- **Issue.** `claude plugin validate .` warns `ICON_MISSING`: the plugin has no square PNG icon (512 to 2048 px, under 2 MB), set through `icon` in `.claude-plugin/plugin.json` or a file at `.claude-plugin/icon.png`.
- **Why not now.** It needs a design choice (what the icon shows) that the plan did not settle, and the listing icon can be fixed only the first time the plugin is submitted, so a placeholder would stick.
- **Trigger.** Before the first submission of the plugin to the developer portal or a public marketplace listing.

**Resolved.** The owner supplied the icon in `assets/icon/`; `plugin.json` now sets `"icon": "./assets/icon/icon-512.png"` (512x512 PNG). `claude plugin validate .` no longer reports `ICON_MISSING`.
